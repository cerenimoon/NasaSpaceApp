# [NasaSpaceApp - CarbonFootprintProject]

## 📌 Overview - Genel Bakış
- This repository features CarbonFootprintProject which is for measuring carbon output of Airline routes between countries (contitents) and encouraging carbon effective approaches with comparison of the carbon outputs of them.
- Bu kod tabanı, ülkeler arası (kıtalar arası) havaalanı rotalarının karbon salınımını ölçen ve bağlantılı karbon salınımlarını karşılaştırarak daha karbon etkin yaklaşımları özendiren CarbonFootprintProject projesini içermektedir. 

## 🚀 Key Features - Anahtar Özellikler
- **Carbon Measurement - Karbon Salınımını Ölçme:** Nasa veri setine ait veriler çekilerek ülkeler arası karbon verilerinden total karbon salınımı hesaplanır. Carbon data from Nasa dataset is used for calculating total carbon output of airline route between countries.  

## 🛠️ Tech Stack & Architecture - Teknik Özellikler ve Mimari
- **Code Area - Kod Alanı:** C# /.NET
- **Database Framework - Veri tabanı Çerçevesi:** Microsoft SQL / SQL
